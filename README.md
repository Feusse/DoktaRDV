# DoktaRDV 🩺

Plateforme de réservation de rendez-vous médicaux au Cameroun.
Trouvez un hôpital, choisissez un médecin et réservez en ligne.

Il faut juste avoir Docker Desktop installé.

docker compose up --build

docker compose down
